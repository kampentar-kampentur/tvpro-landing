# Спецификация 02: Сайдбар: Trending + Promo-блок

Сайдбар является сквозным компонентом для большинства страниц блога (главная страница листинга, страницы категорий, страницы статей) на десктопе.

## 1. Состав и структура сайдбара

Сайдбар содержит два основных виджета, расположенных вертикально:

```
┌──────────────────────────────────────┐
│  TRENDING                            │  ← Виджет популярных статей
│  ──────────────────────────────────  │
│  [Большая карточка (Топ-1)]          │  ← Картинка 16:9 + заголовок
│  [Мини-карточка 2]                   │  ← Картинка 1:1 + заголовок
│  [Мини-карточка 3]                   │
│  [Мини-карточка 4]                   │
│  [Мини-карточка 5]                   │
├──────────────────────────────────────┤
│  📢 PROMO BLOCK                      │  ← Коммерческий баннер
│  ──────────────────────────────────  │
│  🛠 TV Mounting Service               │  ← Оффер
│  From $99                            │
│  [Book Now]                          │
└──────────────────────────────────────┘
```

---

## 2. Детали виджетов

### 2.1 Виджет «Trending» (Популярное)
- **Цель:** Удержание пользователя на сайте и перенаправление на "вечнозеленые" (evergreen) статьи с максимальным трафиком.
- **Логика наполнения:**
  - Топ-5 статей. Выбираются либо автоматически на основе просмотров, либо вручную задаются в CMS (флаг `isTrending: true`).
- **Сетка:**
  - **Топ-1:** Большая карточка. Квадратное или 16:9 изображение, категория (badge), крупный кликабельный заголовок.
  - **Топ 2-5:** Список без картинок или с очень маленькими миниатюрами (40x40px). Только категория, заголовок и дата публикации.

### 2.2 Рекламный Promo-блок
- **Цель:** Конверсия информационного трафика блога в коммерческие заявки.
- **Дизайн:**
  - Не должен выглядеть как классический раздражающий баннер. Должен мимикрировать под элемент интерфейса (карточка с рамкой, чистая типографика, иконка услуги, четкий оффер и кнопка действия).
- **Динамический контент (Контекстные офферы):**
  - Блок должен менять свое предложение в зависимости от того, в какой категории находится пользователь:
    - **Категория TV Mounting / Cable Management:**
      - Оффер: «Professional TV Mounting Services from $99» + УТП: «Same-day booking, certified pros». Кнопка `Book Online`.
    - **Категория Smart Home:**
      - Оффер: «Smart Home & Camera Setup from $149» + УТП: «Ring, Nest & Ecobee compatible». Кнопка `Schedule Setup`.
    - **Категория Home Theater:**
      - Оффер: «Home Theater & Surround Sound Installation». Кнопка `Get a Quote`.
    - **По умолчанию (или для общих страниц):**
      - Общий оффер по монтажу ТВ (основная услуга компании).

---

## 3. Логика позиционирования (Sticky)
- При скролле страницы вниз сайдбар должен оставаться на месте.
- Используется CSS-свойство `position: sticky; top: 20px;`.
- Сайдбар не должен перекрывать футер. Необходимо ограничить высоту контейнера сайдбара и настроить его так, чтобы он останавливался при достижении границы футера (в современных CSS это контролируется вложенностью в `display: grid` родительского контейнера).

---

## 4. Поведение на мобильных устройствах (Responsive)
- На ширине экрана менее **1024px** (планшеты и мобильные) сайдбар перестраивается:
  - Блок `Trending` переносится под основной контент страницы (например, после текста статьи, перед секцией Related Articles).
  - Блок `Promo-блок` трансформируется в компактный горизонтальный баннер (или плавающую кнопку внизу экрана) и показывается в конце статьи.
