# Спецификация 05: Live-поиск и страница результатов (`/blog/search/`)

Внедрение удобного поиска помогает пользователям быстро находить ответы на технические вопросы, что улучшает поведенческие факторы (Time on Site) и снижает показатель отказов.

## 1. Логика Live-поиска (Шапка сайта)

- **Интерфейс:**
  - Иконка лупы (🔍) в основном меню навигации.
  - При клике на неё открывается строка ввода (выезжающая панель или модальное окно на весь экран с фокусом на поле ввода).
- **Автодополнение (Autocomplete / Live Search):**
  - При вводе от 3-х символов запускается поиск по базе статей (по полям `title` и `excerpt`).
  - Результаты показываются мгновенно в выпадающем списке под строкой ввода без перезагрузки страницы.
  - Показывается до 5 наиболее подходящих результатов (миниатюра статьи + заголовок).
  - Внизу выпадающего списка кнопка `See all X results →`, которая перенаправляет на страницу поиска `/blog/search/?q=запрос`.
  - **Дебаунс (Debounce):** Запросы к API должны отправляться с задержкой в 300мс после последнего нажатия клавиши, чтобы снизить нагрузку на сервер/CMS.

## 2. Страница результатов поиска (`/blog/search/`)

- **Адрес страницы:** `/blog/search/?q=search+query`
- **Заголовок (H1):** `Search Results for "search query"`.
- **Количество найденного:** Текст ниже заголовка: `Found 23 articles`.

### 2.1 Сетка результатов
- Список найденных статей в виде вертикального списка (горизонтальная карточка: изображение слева, заголовок и сниппет с подсвеченными ключевыми словами справа).
- Пагинация: 10 результатов на страницу.

### 2.2 Логика «Ничего не найдено» (No Results Found)
Если по поисковому запросу ничего не найдено:
- Выводится текст: `Sorry, we couldn't find any articles matching "query".`
- Выводится альтернативное действие:
  1. Блок со строкой поиска для повторного ввода.
  2. Раздел **«Recommended Articles»** (выводится 3-4 самые популярные статьи из виджета Trending).
  3. Блок с коммерческим CTA: `Need help right away? Talk to our installation experts. [Book Service]`.

---

## 3. SEO поисковых страниц
- **Индексация:** Поисковые страницы должны быть закрыты от индексации поисковыми роботами Google, чтобы избежать проблем с дублированием контента.
- **Метатег:** Добавить `<meta name="robots" content="noindex, follow" />` в `head` страницы результатов поиска.
